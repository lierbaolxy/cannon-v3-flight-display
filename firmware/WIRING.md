# Cannon V3 + DAPLink v1363 接线备忘

## DAPLink 针脚（以 USB 头为参照）

USB 头那一端 → 往另一端数：

| 针序 | 丝印 | 含义 |
|---|---|---|
| 1（靠 USB 头） | 5V | 5V 输出，**不要接** |
| 2 | 3V3 | 3.3V |
| 3 | TMS/IO | SWDIO |
| 4 | GND | 地 |
| 5（最远端） | TCK/CK | SWCLK |

## Cannon 板 P8（USB 座旁，从上到下）

| 针序 | 丝印 | 含义 |
|---|---|---|
| 1 | 3.3V | 3.3V |
| 2 | SWCLK | 时钟 |
| 3 | SWDIO | 数据 |
| 4 | GND | 地 |

## 接线（按信号名对，不要按顺序直插）

| DAPLink | → | Cannon P8 |
|---|---|---|
| 2 · 3V3 | → | 1 · 3.3V |
| 5 · TCK/CK | → | 2 · SWCLK |
| 3 · TMS/IO | → | 3 · SWDIO |
| 4 · GND | → | 4 · GND |
| 1 · 5V | × | 不接 |

⚠️ 若按顺序 1-1/2-2/3-3/4-4 直插，会把 DAPLink 的 **5V 灌进板子的 3.3V**，可能烧稳压器。
